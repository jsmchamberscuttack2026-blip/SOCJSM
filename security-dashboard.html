Turso Cloud Database Protection & Prevention Standards

5 DEFENSE CONTROLS ACTIVE
🔒 Parameterized SQL (Anti-SQLi)

All queries use libSQL typed arguments (zero raw concatenation), rendering SQL injection mathematically impossible.

🔐 Cryptographic Ed25519 Token

Turso access is gated with Ed25519 asymmetric cryptography. Zero tokens are ever exposed to the client browser.

🧱 Air-Gapped DB Separation

Finished cases are purged from MongoDB upon completion and live exclusively in Turso, eliminating single-point data breaches.

🖼️ Image Payload Sanitization

Document uploads are capped at 3 files per case with MIME validation and size guards preventing memory exhaustion.
